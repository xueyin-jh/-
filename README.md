# Snake Game (贪吃蛇)

一个用 Python + pygame 写的贪吃蛇小游戏，同时作为学习 **Git / GitHub** 的练习项目。

## 功能

- 开始界面选择难度：简单 / 普通 / 困难，速度随得分逐渐加快
- 方向键或 WASD 控制移动，不能 180 度掉头
- 吃到食物变长并加分，最高分自动保存到 `highscore.json`
- 特殊食物：青底金框的方块，吃到额外 +3 分，状态栏统计吃到的个数
- TOP5 排行榜：开始界面显示历史最好成绩，成绩保存到 `scores.json`
- 空格暂停，`R` 重新开始，`M` 回开始界面，`ESC` 退出
- 棋盘格背景 + 分数 / 最高分 / 难度 HUD

## 操作

| 按键 | 作用 |
| --- | --- |
| `1` / `2` / `3` | 选择难度并开始 |
| 方向键 / `WASD` | 控制方向 |
| `空格` | 暂停 / 继续 |
| `R` | 游戏结束后重来 |
| `M` | 回到开始界面 |
| `ESC` | 退出 |

## 运行

```bash
pip install -r requirements.txt
python snake.py
```
